# Mi Sitio Web

Página web estática adaptable a móviles y lista para publicar en GitHub Pages.

## Archivos
- `index.html`: estructura y contenido de las cuatro pestañas.
- `styles.css`: diseño responsive y estilos minimalistas.
- `script.js`: navegación entre pestañas y botón Atrás.

## Publicar en GitHub Pages
1. Crea un repositorio en GitHub.
2. Sube estos tres archivos y este README a la raíz del repositorio.
3. Entra a **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`, y pulsa **Save**.
6. Espera a que GitHub Pages publique el sitio y abre la URL que aparece en esa sección.

Las imágenes de ejemplo se cargan desde Unsplash y necesitan conexión a internet. Puedes sustituir sus direcciones por imágenes propias.
